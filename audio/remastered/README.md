# Remastered soundtrack

This directory contains individually arranged clean enemy themes and ambient loops. Enemy files have their own hand-authored tempo, tonal mode, chord path, lead motif, instrument palette, and rhythmic treatment. Boss phase-two themes are composed separately. The four area tracks use distinct instrumentation and environmental textures.

All WAVs are 16-bit mono at 22.05 kHz to match the existing game's delivery format. The original audio remains unchanged under audio/enemies/ and audio/ambient/; the game briefly switches to those original, deliberately unstable versions while the terminal visibly corrupts, then returns to the clean score.
